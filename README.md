# Future Forge 1.2 — Teach. Test. Break. Build.

**This folder is the current version.** The version shows at the bottom of the screen ("Future Forge 1.2.0"), so you can always check you have the right copy open.

**Run it:** double-click `index.html`. It opens in your browser; everything works, including the camera (the browser asks for it each time).

**Launchers (optional):** `START FUTURE FORGE.bat` starts a tiny local server first, so the browser remembers the camera permission and the offline cache works. `START FUTURE FORGE (Edge).bat` does the same but always opens Microsoft Edge. `START FUTURE FORGE (kiosk).bat` is for the booth: full screen, camera allowed without prompts; exit with Alt+F4. If Windows says a launcher "may be unsafe", that copy came from a downloaded zip — use `index.html` instead, or use a copy that was written straight to the computer. Mac equivalents end in `.command`.

**Phones:** put this whole folder on any https web host; the QR code points at that address (see PRINT.md).

**Reset between visitors:** the Reset button, top right. Nothing is saved anywhere.

**Change copy, domains, sensor scenarios or card decks:** edit the files in `content/`. Options live in `config.js`.

Docs: FACILITATOR.md (running the table), TECHNICAL.md (how it works), PRINT.md (signage), ACCESSIBILITY.md (what is built in, what was tested, known limits).
